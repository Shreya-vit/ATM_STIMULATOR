ATM Simulator – Python

 Project Overview

The ATM Simulator is a beginner-friendly Python project that simulates the basic operations of an Automated Teller Machine. The program allows users to securely log in using a PIN and perform common banking transactions such as checking balance, depositing money, withdrawing money, changing the PIN, and viewing transaction history.

This project is developed to understand and apply fundamental Python programming concepts in a practical application.

 Problem Statement

Traditional ATM systems perform several banking operations through secure authentication. The objective of this project is to create a simple ATM simulation using Python that allows users to perform basic banking transactions while implementing PIN verification, balance management, and transaction tracking.

 Features

-  PIN-based authentication
-  Check account balance
 Deposit money
- Withdraw money
-  Change PIN
- View transaction history
-  Insufficient balance validation
-  Three PIN attempts
- Invalid input handling
-  Secure exit option
